# D'Resto

Aplikasi katalog restoran dengan tampilan modern. Proyek ini dibuat sebagai bagian dari submission kelas Flutter di Dicoding.

## Fitur Aplikasi

- Daftar restoran dengan informasi nama, gambar, kota, dan rating
- Detail restoran yang menampilkan informasi lengkap termasuk deskripsi, alamat, menu, dan ulasan
- Pencarian restoran berdasarkan nama, kategori, atau menu
- Penambahan ulasan untuk restoran
- Tema terang dan gelap

## Teknologi yang Digunakan

- Flutter sebagai framework utama
- Provider untuk state management
- HTTP package untuk komunikasi dengan API
- Lottie untuk animasi loading dan placeholder
- Google Fonts untuk kustomisasi font
- Cache Network Image untuk loading gambar efisien

## Cara Penggunaan

1. Pastikan Flutter SDK sudah terinstal pada perangkat Anda
2. Clone repository ini
3. Jalankan perintah `flutter pub get` untuk mengunduh dependensi
4. Pastikan Anda memiliki koneksi internet aktif saat menjalankan aplikasi
5. Jalankan aplikasi dengan perintah `flutter run`
